## 不超售到底怎么验

商家的“不超售”三个字不值钱，值钱的是能拿数据打脸的证据。下面几条按可执行程度排，买之前花二十分钟就能做完。

**看它写不写流量配额。** 标“无限流量”的套餐基本都要靠限速或超售兜底。DMIT 每个套餐都写明每月多少 GB，LiteServer 也一样标 15TB、20TB 这种具体数字。写清配额说明商家知道资源边界在哪。

**要测试 IP 或 Looking Glass。** 有 Looking Glass 的商家允许你从外部直接看这台机器的路由和负载情况。LiteServer 公开了测试 IP 供人自行验证，DMIT 各机房也有测试入口。没有测试手段的商家，只能靠别人的测评碰运气。

**晚高峰测延迟和丢包，测三天。** 时间段选 20:00–23:00，用 ping 和 mtr 连续跑。第三方对 DMIT 洛杉矶 Premium 的实测口径是丢包低于 0.1%、晚高峰延迟稳定在 155–162ms。你自己测出来的数字才算数，别人的只能当参考。

**看热门套餐是不是长期缺货。** 这一点常被忽略。真不超售的商家，物理机资源有限，卖完就是卖完，热门款长期挂着“补货中”反而是正面信号。DMIT 被吐槽最多的缺点正是经常断货、想买的套餐要蹲。

**看它敢不敢公开 CPU 型号和虚拟化方式。** KVM 加明确到 EPYC 系列的 CPU 型号，说明资源是按物理核心切的。只写“高性能 CPU”的，通常有猫腻。

## Pro、EB、T1 三档的真实差别

三档的差别在线路，不在 CPU 和内存。

**Pro 卖的是 CN2 GIA。** 电信顶级优化线路，全程走 AS4809，电信、联通、移动三网都有优化。跑建站、跑需要稳定低延迟的业务，这一档最省心。

**EB 卖的是 CMIN2。** 移动的优化线路，对移动宽带用户特别友好。价格定位比 Pro 低，但入门款不是这样。

**T1 卖的是流量和弹性。** 标准线路，没有回国优化，价格最低，配置上限最高（GIANT 给到 8 核 24GB 和 128TB 月流量）。

## 哪些人不该买 DMIT

说得直白些，这家的缺点和优点一样明确，测评和社区里的集中反馈能归成三类。

**热门套餐经常断货。** 想买 WEE 这种低价年付款，可能要等补货。急着上线业务的，得有备选方案。

**维护通知不及时。** 有反馈提到服务器突然不通、联系客服才知道在升级硬件。跑关键业务的话，自己要做监控和冗余。

**价格高于同类。** 同样的钱在别处能买到更高配置，这是不超售和优质线路的代价。

还有一条藏在退款条款里，比前三条更值得提前知道。条款写明购买 3 天内且流量使用不超过 30GB 可全额退款（扣除支付网关手续费），30 天内可按剩余流量或剩余时间中较高的一项部分退款。但**以“网络状况不佳”为理由提出的退款不予受理**，IP 地理位置原因、遭受 DDoS、同一系列已退款 3 次，也都在不予退款之列。

这条对国内用户很关键：如果你买之前就担心“万一晚高峰卡”，那要先自己用测试 IP 验证，别指望买完不满意再退。所有条款以官网原文为准，下单前自己读一遍。

不适合的还有两类人：需要欧洲节点或大流量存储的，LiteServer 那类荷兰商家更对路；预算极低、只想要一台便宜机器玩玩的，DMIT 最便宜的 T1 也要 $6.90/月，别为难自己。
